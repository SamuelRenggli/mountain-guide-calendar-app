Widget auf deiner Website

Füge diesen Code in deine Website ein (WordPress, Wix, Webflow: Element «HTML» bzw. «Code einbetten»).

<script src="{{ site_url }}{% static 'js/embed.js' %}" data-tourchef="{{ user.slug }}" async></script>

Widget-Vorschau öffnen

Auf einer englischen Website: data-lang="en" ergänzen, damit Gäste ihre E-Mails auf Englisch erhalten. Ohne Angabe gilt die Browsersprache des Gastes.

Falls deine Website keine Scripts erlaubt, verwende ein iFrame:

<iframe src="{{ site_url }}{% url 'widget:show' user.slug %}" title="Buchungskalender" width="100%" height="900" frameborder="0"></iframe>
