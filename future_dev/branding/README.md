# Branding

- `tourchef-logo.avif`: original from the old app (`Old/tourchef/old/app/static/images/`), 423 × 231 px, black on transparent.
- `tourchef-logo.png`: the same image as PNG, so it opens anywhere.

A chef holding up a plate with a mountain on it, with "tourchef" in round hand lettering below.

## Not used in the app yet

- The font is the device's system font.
- The colours are defined in `static/css/app.css` (primary colour forest green `#2f6b4f`).
